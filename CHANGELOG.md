## 0.1.0 — 2026-10-20 (initial MVP)

- CPU/GPU percentages in a transparent, non-activating desktop overlay.
- All exposed Windows GPU engines, including compute, with busiest-engine aggregation and optional NVIDIA NVML fallback.
- Dragging, edge snapping, click-through lock, tray menu and recovery shortcuts.
- Settings for opacity, type size, update interval, topmost behavior and GPU selection.
- Local settings, bounded error logs, single-instance activation and JSON diagnostic mode.
- Ten Core checks covering CPU differences, GPU aggregation, parsing and unavailable readings.

This is an MVP, not a claim of full hardware or interaction certification. See VALIDATION.md.
